Why this exists

Every sales-knowledge tool claims it can onboard a company. Almost none show it on the same messy inputs, scored the same way. Personal finance has public test households; sales knowledge didn't have a public test company. This is one, built only from material its owners publish, with licences recorded per file. Openly licensed files are hosted here; for the rest, each item links to its original and the repository ships a fetch script.

Methods and scores: see the repository README.
